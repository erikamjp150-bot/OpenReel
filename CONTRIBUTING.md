# Contributing to OpenReel

Thank you for your interest in contributing to OpenReel.

## Code of Conduct
Be respectful, inclusive, and constructive.

## Getting Started
1. Fork the repository.
2. Create a feature branch from `main`.
3. Run the project locally before opening a pull request.

## Backend
- Use Python 3.11+.
- Install dependencies from `requirements.txt`.
- Run the FastAPI app with `uvicorn backend.app.main:app --reload`.

## Frontend
- Use React Native.
- Run `npm install` inside `frontend/mobile`.
- Start with `npm start`.

## Style
- Python: PEP 8, type hints, `async` if interacting with I/O.
- JavaScript: ES6 syntax, functional components.

## Pull Requests
- Include tests for new features.
- Keep PRs small and focused.
- Reference issue numbers when applicable.
